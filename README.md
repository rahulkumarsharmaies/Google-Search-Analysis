# Google Search Analysis

A starter project outlining an analysis of how people search for keywords across countries and over time.

## Project goals

- Search for different keywords by changing a single value.
- Identify and visualize the 15 countries with the highest search interest.
- Plot a world map showing search interest by country.
- Explore how search interest changes over time and across years.
- Compare related keywords and visualize the comparison.

## Project files

- [`project-source/project-outline.txt`](project-source/project-outline.txt) — the supplied project outline.
- [`project-source/output.json`](project-source/output.json) — an empty output file supplied with the project.
